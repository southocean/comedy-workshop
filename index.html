How a script is stored

Each line is a beat with a role. The viewer colours them, the timer charges for them, and the inspector explains them.

Setup Punchline Tag One-liner Act-out Callback Sincere
Setups carry a distribution

Not one expectation - all of them, with percentages. A setup that concentrates 90% of the room on a single prediction is worth more than a clever punchline, because it gives you something solid to break.

Punchlines carry an axis

Every punch names what the room expected, what they got, and the axis between them. If the arrow cannot be written in plain language, the line is not a punchline yet.
